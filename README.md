# nabhanri.dev

**Live**: [nabhanri.dev](https://nabhanri.dev)

Personal portfolio website — built from scratch with Next.js, Tailwind CSS, and TypeScript..

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4
- **Language**: TypeScript
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Deployment**: Vercel

## Run Locally

```bash
npm install
npm run dev
